# HokieHub 🦃

> Built at **VTHAX 13** — Virginia Tech's hackathon

HokieHub is an MVP review platform for Virginia Tech students to rate and discover dining halls, study spots, and other places around campus. Think Yelp, but built for Hokies.

---

## Features

- Browse and search Virginia Tech campus locations
- Leave reviews and ratings for dining halls and campus spots
- Helps students make more informed decisions about campus life

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18+ recommended)
- npm (comes with Node.js)

### Installation

```bash
git clone https://github.com/rdunetz/hokiehub.git
cd hokiehub
npm install
```

### Running the App

```bash
npm start
```

The app will be available at `http://localhost:3000` by default.

### Running the Backend

```bash
cd back
node index.js   # or: npm start
```
